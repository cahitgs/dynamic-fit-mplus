Free and open source · Windows · Mplus 8

Dynamic Fit for Mplus

Dynamic fit index cutoffs for confirmatory and second-order factor models, simulated with Mplus on your own computer. The cutoffs separate the fit of your correct model from the fit under a misspecification of known size, with the fit index definitions of the Mplus output you report.

Download for Windows Source on GitHub

A single .exe, nothing to install. Needs Mplus 8.x on the same computer (tested with 8.3; the free demo handles at most 6 items). Your data never leave it; the interface loads its styles and fonts from the web.

What it does

Three ways in

Raw data (the app fits your CFA in Mplus first), an Mplus output file, or standardized estimates typed in from a paper.

One-factor, multi-factor, second-order

Continuous items as normal data with ML, or ordinal items generated from the estimated thresholds and analyzed with WLSMV.

The rules of dynamic

Misspecifications as in the dynamic R package: omitted cross-loadings, or residual correlations of .30 in one-factor models.

CFI in every replication

Mplus 8.3 Monte Carlo does not report CFI, so each condition is rerun with the baseline model on the same seed.

Improper solutions in the open

Replications with a non–positive definite covariance matrix (TECH9) are counted; keep them, as dynamic does, or exclude them.

A paper draft, not just numbers

APA 7 method, results, tables, a figure in black and white or color, and references. Every Mplus file is one click away.

How it works

  1. Data. Choose raw data, an Mplus output or typed-in estimates. A sample data set and a published example are included.
  2. Structure. Assign items to factors, optionally under a second-order factor.
  3. Settings. Ordinal or normal data, number of replications, improper solutions.
  4. Run. Mplus simulates the correct model and every misspecification level, two runs at a time.
  5. Report. The cutoffs, the observed fit and the distributions appear in the paper.

Get started

Windows app

Download DynamicFitMplus.exe from the latest release and double-click it. The app opens in your browser; projects are saved next to the .exe. The file is not signed, so Windows may ask once: More info → Run anyway.

From source

With Node.js 18 or newer, no packages to install:

git clone https://github.com/cahitgs/dynamic-fit-mplus.git
cd dynamic-fit-mplus
node serve.mjs --open
